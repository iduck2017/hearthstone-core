When implementing a card from the existing feature set, follow these steps strictly:

1. Read `src/cards/neutral/todo.md` to get the next card to implement.
2. Read `src/cards/neutral/index.json` to get the card's concrete details.
3. Read the feature index in `src/index.spec.md` to find similar card features.

4. Read the reference implementation of those features.
5. If any required feature is not yet implemented, inspect the core logic and confirm with me.
6. After I approve, add or modify the core logic.
7. Plan the card's implementation and confirm with me.

8. After I approve, implement the card.
9. Confirm with me whether tests are needed.
10. If tests are needed, plan a test scenario first and confirm with me. Follow `src/index.spec.md`
11. After I approve, write the test cases and wait for me to run them.

12. Update `src/cards/neutral/todo.md` to mark the card as done.
13. If appropriate, update `src/index.spec.md` to add any newly introduced representative features.
